# Structures to Avoid

## Binary Contrasts

These create false drama. State the point directly.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." / "Not because X, but because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliché |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." / "not X, it's Y" / "isn't X, it's Y" | Mechanical contrast |
| "It's not this. It's that." | Same formula, different words |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" / "This does not mean X. It means Y." | Negation-then-assertion crutch |
| "is about X but not Y" | False distinction |
| "not just X but also Y" / "not merely X" | Additive hedge |
| "Y rather than X" | The same contrast, reversed |
| "..., no guessing" / "..., no config needed" | Clipped negative tail |

**Instead:** State Y directly. "The problem is Y." "Y matters here." Keep a contrast only when the
negative half corrects a belief the reader holds, or when both halves carry information.

## Negative Listing

Listing what something is *not* before revealing what it *is*. A rhetorical striptease.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same structure, past tense |

**Instead:** State Z. The reader doesn't need the runway.

## Dramatic Fragmentation and Closers

Fragments and one-line closers ask the reader to pause on a claim instead of adding to it.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." / "No X. No Y." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |
| "That is the real win." / "That distinction matters." | Closer that repeats the paragraph |
| The same closer after several sections | Closer by template |
| "This shows the importance of..." / "The message was clear:" after an example | Explains what the reader just saw |
| "every. single. day." / one word in ALL CAPS | Typographic shouting |

**Instead:** Complete sentences. Cut a closer that repeats. Keep a short sentence when it adds a
new fact or consequence.

## Deep-Sounding Sayings

An ordinary point dressed as a hidden truth or an aphorism.

| Pattern | Problem |
|---------|---------|
| "The real question is" / "What really matters is" / "The deeper issue" | Hidden-truth framing |
| "X is the language of Y" / "the currency of" / "the architecture of" | Aphorism template |
| "X becomes a trap when..." | Aphorism template |
| "X is not a tool but a mirror" | Aphorism plus contrast |

**Instead:** Replace the saying with the specific claim.

## Rhetorical Setups

These announce insight rather than deliver it.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |
| "Is it worth it? Honestly?" | Staged candour |

**Instead:** Make the point. Let readers draw conclusions.

## Arguing With No One

The text answers an objection or rejects an option that appears nowhere else, often a leftover
from an earlier draft. Several unrelated rejections in a row are a stronger sign than one.

| Pattern | Problem |
|---------|---------|
| "This isn't (mainly) about X" / "I'm not saying X" | Defends against nobody |
| "To be clear," / "Don't get me wrong," / "This is not to say" | Same |
| "Some might say... but" / "You might think... but" | Invented opponent |
| "A tempting approach would be" / "One might be tempted to" / "It would be easy to just" | Invented alternative |

**Instead:** Delete the defence. If it holds a real claim, state the claim. Keep an objection the
text attributes or answers in full, and an option a reader would weigh.

## Formulaic Constructions

| Pattern | Problem |
|---------|---------|
| "By the time X, I was Y." | Narrative template |
| "X that isn't Y" | Indirect. Say "X is broken" |

## Inflated Significance

The text claims an ordinary detail marks a change, proves a legacy, or promises a future. It shows up as a
phrase, as a stock section, and as a send-off paragraph.

| Pattern | Problem |
|---------|---------|
| "marking a pivotal moment" / "setting the stage for" / "reflects a broader trend" | Significance by phrase |
| "Challenges and Legacy" / "Future Outlook" / "Despite these challenges, X continues to thrive" | Significance by section |
| "The future looks bright" / "Exciting times ahead" | Significance by send-off |

**Instead:** Keep the fact, drop the significance. End on the last concrete fact. If the source
states real plans, use those.

## -ing Riders

An -ing phrase bolted onto a simple fact to make it sound deeper.

| Pattern | Problem |
|---------|---------|
| ", highlighting / underscoring / emphasizing the..." | Claims meaning the fact doesn't carry |
| ", ensuring / reflecting / symbolizing / contributing to..." | Same |
| ", fostering / cultivating / encompassing / showcasing..." | Same |

**Instead:** Keep the fact. Keep the rider only when the source supports what it claims.

## Vague Connection

| Pattern | Problem |
|---------|---------|
| associated with, connected to, linked to, tied to, in connection with | Hides the relationship |

**Instead:** Name the relationship the source gives: founded, caused, runs, depends on. When the
source doesn't say, keep the vague wording rather than invent a role.

## Borrowed Authority

A name or an unnamed authority stands in for what the source said.

| Pattern | Problem |
|---------|---------|
| "Experts argue" / "observers have cited" / "industry reports" / "some critics" | Unnamed authority |
| "featured in [list of outlets]" / "over N followers" | Prestige list |

**Instead:** Name the source and what it said, or cut the claim. A missing citation alone is not
a tell.

## Writing About the Document

The text describes itself or its making instead of its subject.

| Pattern | Problem |
|---------|---------|
| "was added to replace the previous approach" | History in place of behaviour |
| "compiled from" / "anything unconfirmed is flagged rather than guessed" | Method narration |
| "the table below compares" / "this section is organized by owner" | Layout the reader can see |
| A heading followed by a sentence that repeats it | Heading echo |

**Instead:** Describe the subject. Mention a previous version only in changelogs, release notes
and migration guides. Keep a source credit the reader can follow and a caveat that changes what
they should do.

## Writing for the Wrong Reader

A reply rebuilds background the reader already has: the problem, the diagnosis, the evidence, and
the decision last. Each sentence reads fine alone, so this survives sentence-level cleanup. Act on
it only when the text is plainly a reply or you can see the conversation.

**Instead:** Lead with the decision. Keep only the reasoning that would change whether the reader
agrees, usually one fact they lack and any link they need to act.

## False Agency

Giving inanimate things human verbs. Complaints don't "become" fixes. Bets don't "live or die." Decisions don't "emerge." A person does something to make those things happen. AI loves this because it avoids naming the actor.

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | The complaint did nothing. Someone fixed it. |
| "a bet lives or dies in days" | Bets don't have lifespans. Someone kills the project or ships it. |
| "the decision emerges" | Decisions don't emerge. Someone decides. |
| "the culture shifts" | Cultures don't shift on their own. People change behavior. |
| "the conversation moves toward" | Conversations don't move. Someone steers. |
| "the data tells us" | Data sits there. Someone reads it and draws a conclusion. |
| "the market rewards" | Markets don't reward. Buyers pay for things. |

**Instead:** Name the human. "The team fixed it that week" beats "the complaint becomes a fix." If no specific person fits, use "you" to put the reader in the seat.

## Narrator-from-a-Distance

Floating above the scene instead of putting the reader in it.

| Pattern | Problem |
|---------|---------|
| "Nobody designed this." | Disembodied observation |
| "This happens because..." | Lecturer voice |
| "This is why..." | Same |
| "People tend to..." | Armchair sociologist |

**Instead:** Put the reader in the room. "You don't sit down one day and decide to..." beats "Nobody designed this."

## Passive Voice

Passive voice hides the actor.

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |
| "No configuration file needed." | Restore the subject: "You don't need a configuration file." |

**Instead:** Find the actor. Put them at the front of the sentence.

## Sentence Starters to Avoid

| Pattern | Fix |
|---------|-----|
| Sentences starting with What, When, Where, Which, Who, Why, How | Restructure. Lead with the subject or the verb. |
| Several sentences in a row starting with the same subject ("She noted... She noted... She filed...") | Merge them, or open with the action |
| Paragraphs starting with "So" | Start with content |
| Sentences starting with "Look," | Remove |

Wh- openers become a crutch. "What makes this hard is..." becomes "The constraint is..." or better, name the specific constraint.

## Rhythm Patterns

| Pattern | Fix |
|---------|-----|
| Three-item lists, three parallel examples, three facts and a lesson | Use two items or four, or develop the strongest one |
| Questions answered immediately | Let questions breathe or cut them |
| Every paragraph ends punchily | Vary endings |
| Staccato fragmentation | Write full sentences of mixed length |
| "Not always. Not perfectly." | Hedging disguised as reassurance |

## Word Patterns

| Pattern | Problem |
|---------|---------|
| Lazy extremes (every, always, never, everyone, everybody, nobody) | False authority. Use specifics instead of sweeping claims. |
